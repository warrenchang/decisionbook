# Master loop: feedback revision for review

Draft based on the user-supplied Desktop/master-loop.svg. The book’s published figure has not been replaced.

Observe & learn now connects through one shared return path to Notice & interpret, Construct options, Predict consequences, Value consequences, and Choose, commit & act. Five arrowheads touch the right edge of the respective boxes. There is no direct feedback arrow to Context & information, which is treated here as the current decision’s starting input. This diagram convention does not rule out learning changing future information seeking or action changing future circumstances.

The original labels, enclosing frame, forward sequence, and dimensions are preserved. Green distinguishes learning feedback, and the caption now covers revision of decision steps as well as judgments.
